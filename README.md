# SigmaQuoridor

Project for the course "Advanced Machine Learning". Authors: Julia Strzelczyk, Łukasz Wyszomierski, XXX XXX [privacy reasons], Bartosz Pokora, Franciszek Saliński.

Project aims at creating a super-human strength agent for the board game "Quoridor", by implementing and training a miniature version of AlphaZero fit for learning a simpler game than Go with limited resources.
