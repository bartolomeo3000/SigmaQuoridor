# SigmaQuoridor

Project for the course "Advanced Machine Learning". Authors: Julia Strzelczyk, Łukasz Wyszomierski, XXX XXX <privacy reasons>, Bartosz Pokora, Franciszek Saliński.

Project aims at creating a super-human strength agent for the board game "Quoridor", by implementing and training a miniature version of AlphaZero fit for learning a simpler game than Go with limited resources. We'll then compare the performance of AlphaZero-like agent to models based on Reinforcement Learning algorithms, such as Q-learning and SARSA.
